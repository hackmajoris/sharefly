Send a web page as a link.

sharefly uploads a static HTML file or folder from your terminal and prints a link. It works on your machine with zero setup, and for anyone on the internet once you add a Cloudflare Tunnel.

$ sharefly serve report.html
started local sharefly server (pid 4242, log ~/.local/state/sharefly/server.log)
http://127.0.0.1:8080/k7f3x9qa2m/report.html

$ sharefly config set tunnel quick
$ sharefly serve report.html
https://<random-words>.trycloudflare.com/<id>/report.html
expires in 7 days unless you pick another --ttl
brew install --cask hackmajoris/apps/sharefly Builds for macOS and Linux, or build from source with Go.

Everyday commands

The first serve starts a background server for you. It prints only the link, so it pipes into pbcopy or open.

sharefly serve report.html
Share one file. Any file name works.
sharefly serve ./site
Share a folder with an index.html at its root. Use relative links inside it.
sharefly serve report.html --ttl 1h
Choose how long the link lives: 30m, 1h, 3d or never. Default is 7 days.
sharefly ls
See every share with its expiry and link.
sharefly renew <id> --ttl 7d
Push a link's expiry out from now.
sharefly rm <id>
Delete a share. The link stops working at once.

Who can open the link

sharefly runs cloudflared itself when you turn a tunnel on. It never calls the Cloudflare API.

SettingWho can open itWhat you need
tunnel offOnly this machine. The default.Nothing.
tunnel quickAnyone with the link, at a random trycloudflare.com address that changes on each server start.brew install cloudflared
tunnel tokenAnyone with the link, on your own domain. Links that last.A domain on Cloudflare and a tunnel token.
api-addr on TailscaleShare from every device on your tailnet through one host.Tailscale on each device.

Lock a share with a password

Add --password and sharefly generates one. Visitors see a password page; the right password keeps them in until the browser closes.

$ sharefly serve report.html --password
password: k7f3-x9qa-2mzt-c4wq (shown only now)
https://share.yourdomain.com/k7f3x9qa2m/report.html

The password goes to stderr, so | pbcopy still copies only the link. sharefly keeps only a hash: if you lose the password, delete the share and serve it again.

What happens when you run serve

  1. Checks your input before connecting: the TTL, and an index.html in a folder.
  2. Starts the server in the background if none answers on this machine.
  3. Uploads a tar.gz to the server's local API, up to 100MB.
  4. Unpacks it safely: regular files only, size and file-count limits enforced while reading.
  5. Publishes it under a random 10-character ID and prints the link.

Expired shares are removed within 5 minutes. Every page is sent with Cache-Control: private, no-store, so a deleted share doesn't linger in Cloudflare's cache. The file server never lists directories.

One Go binary, standard library only.

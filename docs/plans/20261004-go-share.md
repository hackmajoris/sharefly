# go-share: static HTML sharing via homelab + Cloudflare Tunnel

## Overview
- `go-share serve report.html` (or `serve ./site`) run on any tailnet device uploads the file/folder to the mac mini and prints a public URL `https://share.yourdomain.com/<id>/...`
- solves: quick public sharing of static HTML without third-party hosting; shares outlive the laptop session
- one Go binary, two roles: `go-share server` on the mac mini, client subcommands (`serve`, `ls`, `rm`, `renew`) on laptops
- public exposure via an already-running, dashboard-managed Cloudflare tunnel pointing at the server's local file listener; go-share never talks to cloudflared or the Cloudflare API
- API is designed so the future macOS management app is just another client

## Context (from discovery)
- greenfield: empty directory, no git, Go 1.27.1 available
- environment: Tailscale on all devices, mac mini as always-on homelab, domain on Cloudflare
- decisions made in brainstorm (not re-litigated here): no Caddy, path-based URLs, random IDs, default TTL 7d, tailnet-as-auth, dashboard token tunnel
- dependencies: standard library only

## Solution Overview

```
laptop                                 mac mini
go-share serve x.html ──tailnet──▶ go-share server
                                   ├─ API    <tailscale-ip>:8787  (tailnet only)
                                   ├─ files  127.0.0.1:8080       (no dir listing,
                                   │                               Cache-Control: private, no-store)
                                   └─ <data-dir>/{shares/, tmp/, shares.json}
                cloudflared service (token) ──▶ 127.0.0.1:8080
                https://share.yourdomain.com/<id>/
```

Key decisions:
- **No Caddy**: Cloudflare terminates TLS; Go `http.FileServer` is enough
- **Two listeners**: management API only reachable on the tailnet; public listener bound to loopback, reached only through cloudflared
- **Tailnet is auth**: no API token (tailnet contains only the owner's devices)
- **Random 10-char base32 ID**: unguessable link is the access control
- **`Cache-Control: private, no-store`**: without it Cloudflare edge caches `.js/.css/images`, so `rm`/expiry would not take effect
- **Delete dir before record**: a crash between steps must leave a harmless dangling record, never an orphaned public dir
- **Config = flags + env, no config file**: avoids a TOML dependency (deviation from brainstorm's `config.toml`, simpler):
  - client: `--server` flag, else `GO_SHARE_SERVER` env, else `http://macmini:8787`
  - server: flags `--api-addr`, `--public-addr` (default `127.0.0.1:8080`), `--data-dir` (default `~/go-share`), `--public-url` (required); set in the launchd plist

## Technical Details

**Layout**
```
cmd/go-share/main.go        subcommand dispatch (stdlib flag, one FlagSet per subcommand)
cmd/go-share/server.go      `server` subcommand wiring
cmd/go-share/client.go      `serve|ls|rm|renew` subcommands
pkg/share/                  ttl.go id.go store.go extract.go sweep.go (+ tests)
pkg/server/                 api.go files.go (+ tests)
pkg/client/                 archive.go client.go (+ tests)
deploy/com.go-share.server.plist
```

**Record** (`shares.json` = JSON array)
```json
{"id":"k7f3x9qa2m","name":"report.html","entry":"report.html",
 "size":20480,"created_at":"2026-10-04T10:00:00Z","expires_at":"2026-10-11T10:00:00Z"}
```
- `expires_at: null` = never
- `entry`: path to open, relative to the share dir; `""` = dir root (served `index.html`)
- `size`: total uncompressed bytes

**TTL**: `Nd`, `Nh`, `Nm` (positive integer N) or `never`; anything else → error (400 at API)

**Upload**: `POST /shares?ttl=7d&name=report.html`, body = tar.gz stream
1. `http.MaxBytesReader` on body (100MB) + count uncompressed bytes during extraction (100MB cap, stops gzip bombs) → 413
2. generate ID (retry on collision with existing record/dir)
3. extract into `<data-dir>/tmp/<id>/`; reject entries with `..`, absolute paths, symlinks, hardlinks, anything other than regular files and dirs → 400; tmp dir removed on any failure
4. determine `entry`: `index.html` at root → `""`; else exactly one regular file → that file; else 400
5. `os.Rename` tmp → `<data-dir>/shares/<id>/` (same filesystem)
6. append record, save `shares.json` (mutex; write temp file + rename)
7. respond `201 {"id","url","expires_at"}`, `url = public-url + "/" + id + "/" + entry`

**API** (Go ServeMux method+path patterns)

| Method | Path | Success | Errors |
|---|---|---|---|
| `POST` | `/shares` | 201 record + url | 400, 413, 500 |
| `GET` | `/shares` | 200 `[records + url]` | 500 |
| `DELETE` | `/shares/{id}` | 204 | 404, 500 |
| `POST` | `/shares/{id}/renew` body `{"ttl":"7d"}` | 200 record + url | 400, 404, 500 |

Errors: `{"error":"..."}`.

**Sweep** (startup + every 5 min): for each record with `expires_at <= now`: `os.RemoveAll(dir)` then remove record and save.
**Reconcile** (startup only): dirs under `shares/` with no record → `RemoveAll`; records with no dir → drop; clear `tmp/`.

**Public file server**: `http.FileServer` over a wrapped `http.FileSystem` whose `Open` returns not-exist for directories lacking `index.html` (so no listing anywhere, including `/` and share subdirs); middleware sets `Cache-Control: private, no-store`.

**Client archive**: file → tar with one entry (base name); dir → walk contents relative to root, skip `.git/` and `.DS_Store`, skip symlinks with a warning; dir without `index.html` → error before any network call.

**Client errors**: connection failure → `can't reach go-share server at <addr> (tailscale up? server running?)`, exit 1; API error → print server's `error`, exit 1.
